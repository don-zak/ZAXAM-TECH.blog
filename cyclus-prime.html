Cyclus Prime

An experimental symbolic strategy game in which five elements shape every move against an adversarial force known as n'yar.

Public build

A browser-playable founder-beta build is publicly indexed on itch.io under the title cyclus-prime-founder-beta-itch-fixed.zip. The public demo is intentionally smaller than the private project and is designed as a clean runtime edition.

Current public positioning

Strategy · Browser-playable · Experimental / abstract · Turn-based elements · Founder beta.

Development direction

The broader Cyclus Prime project continues privately beyond the public demo. Current private-project artifacts indicate ongoing work on runtime behavior, view matching and safe relationship/state logic. The public page should therefore be treated as a demonstrable playable slice rather than the complete final game.
