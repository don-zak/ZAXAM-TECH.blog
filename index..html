01 · Methodology

How We Measured

This report applies a Multi-Criteria Decision Making (MCDM) framework using weighted scoring across five capability domains. Each platform was evaluated independently against documented specifications and observable behavior. No platform had editorial input.

Scoring Scale

Each criterion is scored 0–10. Scores reflect documented capability, not marketing claims. Partial implementations receive proportional credit. Missing features score 0.

Weight Distribution

Weights assigned by domain importance for production-grade automation: NLP Intelligence 28% · Tool Coverage 24% · Execution 20% · Governance 16% · UX 12%.

Platforms Selected

NARSY, Make.com (Integromat), n8n, Zapier AI, and Microsoft Power Automate AI — chosen as representative of the low-code AI automation market as of 2026.

Statistical Approach

Final composite scores use additive weighting. Radar charts show normalized per-domain profiles. Gap analysis uses percent-difference from category leader.

⚠

Objectivity note: NARSY is an Arabic-first platform with a domain-specific design philosophy. Comparators are general-purpose automation tools. This creates inherent asymmetries — the report explicitly flags these where they affect interpretation.

09 · Gap Analysis

Where NARSY Trails

Objectivity requires documenting weaknesses. The waterfall chart below shows NARSY's gap from the category leader on each sub-dimension where it does not lead.

Identified Gaps

Third-party integrations — Comparators connect to thousands of SaaS apps natively; NARSY's connector model is more limited today.

Visual workflow editor — n8n and Make.com offer drag-and-drop canvas builders; NARSY is chat-first only.

Cloud persistence — NARSY uses localStorage; competitors offer team-shared workflow libraries and version history.

Strategic Opportunities

MENA market lock-in — No comparator offers Arabic-first UX. First-mover advantage in Gulf, Levant, North Africa.

Regulated sector fit — Built-in governance + risk tiering aligns with SAMA, UAE CBUAE, and Jordan CBJ digital compliance requirements.

Offline capability — Single-file deployment with local NLP is uniquely suited for air-gapped or low-bandwidth environments.
